# Portfolio — Marie Aymeric Dyomenin

Site portfolio personnel d'un étudiant en **Licence 2 Informatique et Génie Logiciel** à l'Institut Ivoirien de Technologie (IIT), Abidjan. Il présente mon parcours, mes compétences, mes projets et mes moyens de contact.

## Aperçu

Le site est une page unique avec un thème **noir / rouge / blanc**. Il est responsive : il s'adapte aux ordinateurs, tablettes et téléphones.

## Sections

- **Accueil** : présentation et boutons vers mes projets, mon contact, GitHub et LinkedIn
- **Qui je suis** : profil et informations clés
- **Ce que je sais faire** : compétences (C, Python, Java, HTML, CSS, notions de Flutter, VS Code, GitHub)
- **Ce que j'ai fait** : sites web, exercices et programmes, initiation à Flutter
- **CV / Formation** : parcours scolaire et universitaire
- **Contact** : coordonnées, liens vers mes réseaux et formulaire de message

## Fonctionnalités

- Design responsive avec Bootstrap 5
- Menu de navigation fixe avec lien actif selon la section affichée
- Animations JavaScript légères :
  - apparition des éléments au défilement
  - barre de progression du défilement
  - ombre du header au scroll
  - bouton « retour en haut »
  - fermeture automatique du menu mobile
- Animations désactivées automatiquement pour les utilisateurs qui préfèrent réduire les animations
- Le contenu reste visible même si JavaScript est désactivé

## Technologies

- HTML5
- CSS3 (variables CSS, animations)
- JavaScript (vanilla)
- [Bootstrap 5.3](https://getbootstrap.com/)
- Polices Google Fonts : Space Grotesk et Inter

## Lancer le projet en local

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/marieaymeric/NOM-DU-DEPOT.git
   ```
2. Ouvrir le dossier, puis double-cliquer sur `index.html` pour l'ouvrir dans le navigateur.

Aucune installation n'est nécessaire. Une connexion Internet est requise pour charger Bootstrap et les polices.
